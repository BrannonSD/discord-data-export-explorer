# 💬 Discord Data Export Explorer v1.3.1 Release Notes

A UI refinement, styling polish, and showcase upgrade release for **Discord Data Export Explorer**.

---

## 🌟 What's New in v1.3.1

### 🔍 UI Polish & Search Bar Sizing Fix
- Fixed SVG dimensions for `.search-icon-small` in the channel header search bar to prevent oversized rendering across high-DPI displays.
- Refined URL auto-link parser sequencing in the full-fidelity Discord markdown engine to ensure flawless attribute handling for custom Discord animated/static emojis.

### 🎨 Complete Theme Showcase
- Added comprehensive real 2x Retina screencaps showcasing all non-default themes:
  - 🖤 **Midnight AMOLED** (Deep pitch black)
  - ☀️ **Discord Light** (Clean light mode)
  - 🌌 **Cyberpunk Neon** (Vibrant blue & cyan accents)
  - 🌸 **Sakura Pastel** (Pastel rose aesthetic)
- Updated documentation with interactive comparison gallery.

### 🚀 Standalone Windows Binary
- Recompiled standalone executable `DiscordDataExportExplorer.exe` (11.00 MB) with all v1.3.1 frontend and backend assets embedded.
